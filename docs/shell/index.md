# Shell guide

[← Previous: Ghostty](../ghostty.md) · [Docs index](../index.md) · [Next: Daily commands →](daily.md)

Start with [Daily commands](daily.md). You only need a few entry points; the category pages keep the rest available when you need them.

| I want to… | Start here |
|---|---|
| Find a command or recipe | `how`, `tools`, Ctrl+G |
| Browse files / jump directories | `y`, `z name`, `zi` |
| Review Git work | `lg`, `gs`, `gd`, `gds` |
| Resume a project | `work` |
| Find an old command | Ctrl+R |
| Find a file / complete arguments | Ctrl+T / Tab |
